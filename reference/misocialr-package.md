# misocialr: Access the Brazilian 'MDS' Social Information Matrix ('MI Social') API from 'R'

'Tidyverse'-friendly interface to the 'MI Social' API of the Brazilian
Ministry of Development and Social Assistance ('MDS', 'SAGI')
<https://aplicacoes.mds.gov.br/sagi/servicos/misocial>. Retrieves
monthly municipal series of the 'Cadastro Unico' (registered families
and people by income bracket), the 'Bolsa Familia' programme
(beneficiary families, benefits and transfers), the 'BPC' benefit, the
social assistance network ('CRAS', 'CREAS' and other units), 'SUAS'
funding, 'Bolsa Familia' conditionality monitoring and food security
programmes as tidy long-format 'tibbles'.
